# Dots 닷츠

**흩어진 경험을 자기소개서·면접 이야기로 정리해 주는 웹 서비스**

취업을 준비하다 보면 "이 경험을 자기소개서에 어떻게 쓰지?", "면접에서 이 질문엔 어떤 경험을 꺼내지?" 하고 막힐 때가 많습니다.
Dots는 경험 하나를 적으면 AI가 질문을 던져 기억을 끌어내고, 그 답을 **STAR 원고 → 역량 키워드 → 역량 연결 → 자기소개서 글**까지 차례로 정리해 줍니다.

> 점(Dot) 같은 경험을 하나씩 이으면, 나의 이야기가 됩니다.

---

## 무엇을 할 수 있나요?

### 1. 경험 하나 적기
경험 이름, 시기, 역할만 적으면 시작합니다. 예) "학과 축제 먹거리 부스 운영 · 2025년 5월 · 부스 총괄"

### 2. AI 질문에 답하기
**상황 → 목표 → 행동 → 결과 → 배운 점** 순서로, 단계마다 2~4개씩 질문합니다.
- 반말·짧은 답도 괜찮습니다. 정리는 AI가 합니다.
- 답이 비어 있거나 모호하면 그 부분만 다시 묻고, 왜 묻는지 한 줄로 알려 줍니다.
- "기억 안 남"을 누르면 그 질문은 다시 묻지 않습니다.
- 단계가 끝나면 "AI가 이해한 내용"을 보여 주고, 틀린 곳은 직접 고칠 수 있습니다.

### 3. STAR 원고 받기
답을 모아 **상황(S) · 과제(T) · 행동(A) · 결과(R) · 배운 점**으로 정리한 원고를 만듭니다.
**말하지 않은 숫자·성과·감정은 지어내지 않고**, 빈 곳은 "(확인 필요)"로 남깁니다.

### 4. 역량 키워드와 역량 연결
원고에서 어필할 역량 키워드를 뽑고, 아래 7가지 역량 중 **대표 1개 + 보조 최대 2개**에 연결합니다.

| 역량 | 이런 경험이에요 |
|---|---|
| 문제 해결 | 문제를 정의하고 원인을 찾아 해결한 경험 |
| 도전적 요소 | 해 본 적 없는 방식에 도전한 경험 |
| 판단·의사결정 | 여러 선택지 중 근거를 갖고 고른 경험 |
| 시행착오·실패 | 잘 안 된 일에서 원인을 찾아 다시 해 본 경험 |
| 협업·조직 역할 | 팀 안에서 맡은 역할로 결과에 기여한 경험 |
| 갈등 조율 | 의견이 갈렸을 때 합의를 이끈 경험 |
| 몰입 동기 | 누가 시키지 않아도 끝까지 붙잡은 경험 |

### 5. 자기소개서 글로 완성하기 (스토리)
원고를 **소제목 + 문단** 형태의 자기소개서 글로 바꿉니다.
- 문항과 글자 수를 정할 수 있고, 글자 수는 공백 포함·제외 모두 보여 줍니다.
- 직접 고치기, 다시 만들기, 복사하기를 할 수 있습니다.
- 한 경험으로 문항마다 다른 글을 여러 개 만들 수 있습니다.

### 홈 화면
- 역량 7개가 **빨주노초파남보 구슬**로 보이고, 정리한 경험이 많을수록 채워집니다. 비어 있는 역량은 다음에 꺼낼 경험의 힌트입니다.
- 역량을 고르면 그 역량에 연결된 경험이 목록으로 나오고, 누르면 결과물 카드가 펼쳐집니다.
- 정리한 STAR 원고를 **TXT · Word · MD 파일**로 내려받을 수 있습니다.

## 직접 실행해 보기

처음 해 보는 분도 따라 할 수 있게 적었습니다. 명령은 "터미널"(윈도우는 PowerShell 또는 명령 프롬프트, 맥은 터미널)에 입력합니다.

### 준비물
1. **Node.js 20.9 이상** — [nodejs.org](https://nodejs.org)에서 LTS 버전을 설치합니다.
2. **Claude API 키** — [console.anthropic.com](https://console.anthropic.com)에서 발급합니다. AI 질문·원고 생성에 쓰입니다. (키 없이 둘러보려면 아래 "시연 모드"를 보세요.)

### 순서
```bash
# 1. 코드 내려받기
git clone https://github.com/junhyunu/dots.git
cd dots

# 2. 필요한 프로그램 설치 (처음 한 번)
npm install

# 3. API 키 파일 만들기
#    맥/리눅스:  cp .env.example .env.local
#    윈도우:     copy .env.example .env.local
#    만든 .env.local 파일을 열어 ANTHROPIC_API_KEY= 뒤에 발급받은 키를 붙여 넣습니다.

# 4. 실행
npm run dev
```

브라우저에서 **http://localhost:3000** 을 열면 됩니다.

> `.env.local`에 넣은 키는 내 컴퓨터에만 있고, 저장소(GitHub)에는 올라가지 않습니다.

### API 키 없이 둘러보기: 시연 모드
**http://localhost:3000/demo** 를 열면 가상 경험 20여 개가 채워진 화면을 볼 수 있습니다.
- AI 대신 정해 둔 대본으로 답해서 **API 키가 없어도, 요금 없이** 모든 기능을 써 볼 수 있습니다.
- [새 경험 시연]을 누르고 질문마다 [예시 답변 넣기]만 누르면 처음부터 자기소개서 글까지 진행됩니다.
- 시연 데이터는 실제 데이터와 따로 저장됩니다. [나가기]를 누르면 실제 화면으로 돌아갑니다.

---

## 내 데이터는 어디에 저장되나요?

- 작성한 내용은 **내 브라우저에만** 저장됩니다(localStorage). 로그인도, 서버 저장도 없습니다.
- 새로고침해도 작성 중이던 내용이 남아 있습니다.
- 브라우저 데이터를 지우거나 다른 브라우저·기기에서 열면 보이지 않습니다. 중요한 원고는 파일로 내려받아 두세요.
- AI 기능을 쓸 때는 질문을 만들기 위해 해당 경험 내용이 Claude API로 전송됩니다. 이 서비스의 서버는 요청을 전달만 하고 아무것도 저장하지 않습니다.

## 자주 쓰는 명령

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발용으로 실행 (http://localhost:3000) |
| `npm run build` | 배포용으로 묶기 (오류가 없는지 확인할 때도 씀) |
| `npm run start` | 배포용으로 묶은 것을 실행 |
| `npm run typecheck` | 코드 타입 검사 |

## 사용한 기술

| 기술 | 쓰는 곳 |
|---|---|
| Next.js (App Router) · React · TypeScript | 웹 화면과 AI 요청 창구 |
| Tailwind CSS v4 | 화면 디자인 (원티드 디자인 시스템 "몽타주" 기반) |
| Claude API (`@anthropic-ai/sdk`) | 질문·원고·키워드·자기소개서 글 생성 |
| zustand | 브라우저 저장(localStorage) |
| WebGL2 | 홈의 역량 구슬 그림 (React Bits "Strands" 셰이더 기반) |
| docx | Word 파일 내려받기 |
| lucide-react · Pretendard | 아이콘 · 글꼴 |

## 폴더 구조

```
dots/
├─ src/
│  ├─ app/            화면 주소( / 홈, /work 작업 화면, /demo 시연 )와 AI 요청 창구(api/generate)
│  ├─ components/     화면 부품 (홈, 질문, 원고, 역량 연결, 스토리, 시연 모드)
│  ├─ content/        홈 예시 3개, 시연용 가상 경험과 AI 대본
│  └─ lib/            데이터 구조·규칙, AI 요청, 브라우저 저장, 파일 내려받기
├─ 프롬프트.md         AI에게 주는 지시문 (코드와 분리해 관리)
├─ CLAUDE.md          서비스 기준 문서 (흐름, 규칙, 데이터 구조)
├─ design.md          디자인 기준 (색, 글자, 부품)
└─ 기록/              날짜별 작업일지, AI 활용 기록
```
